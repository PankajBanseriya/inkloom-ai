# Feature Modules Directory

Feature-specific components, hooks, and modals will be placed here in corresponding feature folders:
- `auth/`: Login, registration, role selection
- `brands/`: Brand workspace selector & configuration
- `guidelines/`: Prohibited/required terms & tone rule managers
- `claims/`: Approved claims ledger
- `sources/`: Evidence & source document repository
- `reviews/`: Content editor & review submission
- `evidence/`: Evidence cards & citation inspector
- `revisions/`: Intent Lock diff viewer & revision timeline
- `approvals/`: Reviewer queue & decision actions
- `analytics/`: Clarity heatmap & guideline conflict indicators
